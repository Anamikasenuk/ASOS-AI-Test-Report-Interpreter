Two ways to load reports — you can mix and match, add more any time:
  1. Upload PDFs directly — drop several files at once below, or choose multiple in the file picker (Ctrl/Cmd-click to select more than one).
  2. Or paste the text — open each PDF, select all (Ctrl/Cmd+A), copy, and paste into the box. You can paste multiple reports one after another into the same box — the tool automatically splits them wherever a new "Test Report:" begins.
PDF reading is done with a text extractor written from scratch — tested against real Bureau Veritas reports, but PDF internals vary by generator. If extraction looks wrong or incomplete for a given report, the paste method will always be the reliable fallback.
For failed tests, the tool now also tries to pull the actual measured result and the requirement/limit it was checked against — including full per-property breakdown tables for Bureau Veritas–style detailed results grids (Tested Property / Requirements / Results / Rating). This is heuristic — layout varies by report generator — so always cross-check flagged values against the source PDF. If it's missing or wrong for your reports, share a redacted sample and the extraction can be tuned further.
